# BinNova Architecture

## System Overview

BinNova is an ESP32-based smart waste management prototype.

## Data Flow

1. Sensors measure bin fill level and related conditions.
2. The ESP32 reads sensor values.
3. The firmware updates indicators and the display.
4. Network connectivity supports monitoring and alert workflows.

## Modules

- Sensor input and calibration
- Fill-level processing
- Display and status indicators
- Network and web-server functions
- Notification integration

Refer to the firmware and hardware configuration for the implemented features.
